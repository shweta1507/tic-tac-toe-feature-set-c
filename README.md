# AI Tic-Tac-Toe – Feature Set C

## Problem Statement
Tic-Tac-Toe Game.

## Assigned Feature Set C
- Player vs computer
- Difficulty selection
- Score tracking
- Game history
- Replay option

## Features Implemented
- Player (X) vs Computer (O)
- Easy, Medium and Hard difficulty
- Hard mode uses the Minimax algorithm
- Winner/draw detection
- Score tracking
- Game history
- Replay/New Game
- Clear history
- Sound On/Off
- Responsive mobile-friendly interface

## Technologies Used
- Python (primary programming language)
- Flask
- HTML
- CSS
- JavaScript

Python/Flask serves the application and handles the computer AI, winner logic, and score/history API. JavaScript provides the browser interaction and board display.

## AI Tools Used
ChatGPT and Bolt.new were used as learning and development assistants.

## Important AI Usage
AI was used for problem understanding, planning, coding, debugging, testing ideas, UI improvement and documentation. The submitted code should be reviewed, tested and understood by the student.

## How to Run
1. Install Python 3.
2. Open a terminal in this project folder.
3. Run `pip install -r requirements.txt`.
4. Run `python app.py`.
5. Open `http://127.0.0.1:5000` in a browser.
